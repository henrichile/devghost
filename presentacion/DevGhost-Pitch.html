😰 El Problema

¿Cuántas horas has perdido tratando de entender código ajeno?

  • Un developer nuevo tarda 3-6 meses en ser productivo en un proyecto existente
  • Las auditorías de código toman semanas de revisión manual
  • La documentación técnica siempre está desactualizada o no existe
  • Entender la arquitectura requiere leer miles de líneas sin contexto
  • Los casos de uso y requerimientos se pierden con el tiempo

Resultado: tiempo perdido, decisiones sin contexto, bugs por desconocimiento de la estructura, y onboarding eterno.

04 / 09

🧠 Arquitectura Técnica

DAG Execution Engine

  • Grafo de dependencias (DAG) entre agentes
  • Concurrency Limiter con asyncio.Semaphore
  • Retry con backoff exponencial configurable
  • Timeout individual por agente
  • Agregación de resultados con prioridad
  • Tolerancia a fallos parciales

Stack Tecnológico

  • Backend: Python + FastAPI + asyncio
  • Parser: Tree-sitter (análisis AST real)
  • LLM: Gemini AI para generación
  • Frontend: React + ReactFlow + Mermaid
  • Streaming: SSE con secuencia atómica
  • Deploy: Docker Compose
